muvid.subgenres._contract

What a subgenre renderer is handed, and what it must give back.

A typing.Protocol rather than a base class: a plugin author writes a plain function and never imports a muvid class to inherit from, and muvid can type-check the shape without either side depending on the other at runtime.

The request carries paths and primitives only. That is the load-bearing decision in this module. Passing a rich host object (Sphinx’s app, MkDocs’ config, Datasette’s datasette) is the well-documented way to end up unable to change your own schema for years, because every plugin has reached into it. A plugin that needs more than this asks muvid through a narrow accessor function, and that request becomes a visible, versionable API change.

class muvid.subgenres._contract.RenderRequest(*, subgenre: str, inputs: ~typing.Mapping[str, ~typing.Any], params: ~typing.Mapping[str, ~typing.Any] = <factory>, workdir: ~pathlib.Path, output: ~pathlib.Path)[source]

Everything a subgenre renderer gets.

Parameters:

  • subgenre – the slug being rendered, so one function can serve several.

  • inputs – the caller’s files and primitives, validated against the manifest’s inputs schema before it gets here.

  • params – the styling/treatment knobs, validated against params_schema.

  • workdir – a directory the renderer may write intermediates into. It exists, and it belongs to this render — nothing else writes there.

  • output – where the finished artifact must be written.

class muvid.subgenres._contract.RenderResult(*, output: Path, duration_s: float | None = None, artifacts: Mapping[str, ~pathlib.Path]=<factory>, meta: Mapping[str, ~typing.Any]=<factory>)[source]

What a renderer gives back.

Parameters:

  • output – the finished artifact. Must be the request’s output.

  • duration_s – length of the produced media, when it has one.

  • artifacts – named side products worth keeping — a .ass subtitle file, a thumbnail, the resolved treatment spec. These are how a subgenre stays inspectable instead of producing an opaque file.

  • meta – anything else worth recording; must be JSON-able.

class muvid.subgenres._contract.Renderer(*args, **kwargs)[source]
